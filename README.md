# java-homework
Репозиторий для хранения и проверки домашних заданий по Java.

Каждый участник размещает свои решения в отдельной директории. Изменения в основную ветку `main` вносятся через Pull Request после проверки.

### Структура репозитория

```text
java-homework/
├── README.md
├── CONTRIBUTING.md
├── .gitignore
├── .github/
│   └── workflows/
│       └── java-check.yml
├── homework/
│   ├── vasileva/
│   │   ├── hw-01/
│   │   │   └── src/
│   │   │       └── Main.java
│   │   └── hw-02/
│   │       └── src/
│   │           └── Main.java
│   └── <username>/
│       ├── hw-01/
│       └── hw-02/
└── shared/
    ├── README.md
    └── examples/
```
### Назначение директорий

#### `homework/`
Индивидуальные решения домашних заданий участников группы.
Каждый участник работает только в своей директории:
```text
homework/<username>/
```
Пример:
```text
homework/vasileva/
```

#### `hw-01`, `hw-02`
Отдельные домашние задания.
Каждое задание хранится в собственной директории:
```text
homework/vasileva/hw-01/
```

#### `src/`
Исходный код конкретного задания:
```text
homework/vasileva/hw-01/src/Main.java
```
Для небольших заданий используется класс `Main`.

#### `shared/`
Общие материалы группы: примеры кода, демонстрации с занятий и вспомогательная документация.
В `shared/` не размещаются индивидуальные решения участников.

#### `.github/workflows/java-check.yml`
Workflow для автоматической проверки Java-кода:
- компиляция исходников;
- запуск Checkstyle;
- проверка изменений при push и Pull Request.

### Основные правила

- Для каждого участника используется отдельная директория.
- Каждая домашняя работа хранится в отдельной директории `hw-XX`.
- Изменения в `main` вносятся через Merge Request.
- Прямой push в `main` запрещён.
- Перед созданием Merge Request необходимо проверить код локально.
- Нельзя добавлять в репозиторий `.class`, `build/`, `.idea/`, `.vscode/` и другие временные файлы.
- Нельзя изменять директории других участников без согласования.

Подробные правила находятся в [CONTRIBUTING.md](CONTRIBUTING.md).
